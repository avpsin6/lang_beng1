# HealthLens

Private, offline analysis of your Apple Health / Apple Watch export. It turns
the export from your iPhone into:

* a **report** (`report.html`): written findings and charts for activity, heart
  & fitness, sleep, workouts, year-by-year change and how your measures relate;
* a **dashboard** (`dashboard.html`): pick any dates and any measure and explore.

Both are single HTML files that open in any browser and work without internet.

> HealthLens describes patterns in your data. It is not a medical device and
> cannot diagnose anything. Talk to a doctor about any health concern.

## Privacy

* Everything runs on your computer. There are no network requests, no
  telemetry and no AI services. The generated pages carry a browser policy
  that blocks all network access.
* Your data and reports live in `~/HealthLens/`, **outside this repository**.
  This repository is public; `.gitignore` also blocks exports, caches, CSVs
  and reports from being committed. Never put your export inside the repo.
* The report files contain your health data. Share them only with people you trust.

## 1. Get your data off the iPhone

1. Open the **Health** app and tap your profile picture (top right).
2. Tap **Export All Health Data** and wait (it can take several minutes).
3. Send the resulting `export.zip` to your computer (AirDrop, Files, a cable).
   Avoid email or chat apps for this file.

You do not need to unzip it.

## 2. Install (once)

### Windows

1. Open https://github.com/avpsin6/lang_beng1, click the green **Code** button,
   choose **Download ZIP**, and unzip it (for example into your Documents folder).
2. Open the unzipped folder and double-click **install.bat**.
   * If Python isn't installed, it offers to install it for you (with Windows'
     own `winget` tool) and asks before doing so.
   * Windows may show a SmartScreen warning because the script isn't signed:
     click **More info**, then **Run anyway**.
3. Wait for "HealthLens is installed".

In that folder, click the address bar, type `cmd` and press Enter to open a
command window. Then use `healthlens` as shown below.

### Mac or Linux

You need Python 3.9 or newer.

```bash
git clone https://github.com/avpsin6/lang_beng1.git
```

```bash
cd lang_beng1
```



```bash

```

## 3. Use

Try it first on a synthetic person (no real data needed):

```bash
healthlens demo
```

Then run it on your own export:

```bash
healthlens run ~/Downloads/export.zip
```

On Windows the export path looks like `C:\Users\you\Downloads\export.zip`.

This reads the export, writes `~/HealthLens/reports/report.html` and
`dashboard.html`, and opens the report. A large export (several GB unzipped)
takes a few minutes the first time; later runs reuse the parsed data.

Other commands:

| Command | What it does |
|---|---|
| `healthlens report` / `healthlens dashboard` | Rebuild a page from the last import |
| `healthlens report --units imperial` | Force miles / pounds (default: whatever your iPhone used) |
| `healthlens info` | List the devices and data types found in your export |
| `healthlens export-csv` | Daily, nightly and workout tables as CSV files |
| `healthlens clear --yes` | Delete the imported data and reports |
| `healthlens --home <folder> ...` | Use a different folder than `~/HealthLens` |

## How it works

```
export.zip -> parser -> Parquet cache -> daily / sleep / workout tables -> findings -> HTML
```

See [docs/METHODOLOGY.md](docs/METHODOLOGY.md) for how each number is made and
its limits, and [docs/REVIEW_GUIDE.md](docs/REVIEW_GUIDE.md) for the build
phases and the decisions behind them.
